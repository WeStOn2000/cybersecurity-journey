# 📊 Data

Data is information that is created, stored, processed, or transmitted
by computer systems.

In cybersecurity, protecting data is one of the main objectives.

Data can exist in different states.

---

## 💾 Data at Rest

**Data at rest** is information that is currently being stored rather
than actively transmitted.

Examples:

- Files stored on an SSD
- Information inside a database
- Photos stored on a phone
- Files stored on a USB drive

Encryption and access controls can help protect sensitive data at rest.

---

## 🌐 Data in Transit

**Data in transit** is information moving between devices or systems.

Examples:

- Sending an email
- Loading a website
- Transferring a file
- Communicating with a server

Protocols such as HTTPS help protect data while it travels across
networks.

---

## ⚡ Data in Use

**Data in use** is information currently being processed by a computer.

For example, when an application loads information into RAM so that
the CPU can process it, that information is being used by the system.

---

# 🔐 The CIA Triad

The **CIA Triad** is a foundational cybersecurity model.

CIA stands for:

- Confidentiality
- Integrity
- Availability

These three principles help describe what cybersecurity professionals
are trying to protect.

---

## 🔒 Confidentiality

**Confidentiality** means information should only be accessible to
authorized people and systems.

Security controls that can help protect confidentiality include:

- Passwords
- Permissions
- Encryption
- Multi-Factor Authentication (MFA)

### Question to remember:

**Who is allowed to see this information?**

---

## 🧾 Integrity

**Integrity** means information should remain accurate and should not
be changed without authorization.

Security controls that can help protect integrity include:

- File hashes
- Digital signatures
- Access controls
- Logging

### Question to remember:

**Can I trust that this information has not been improperly changed?**

---

## 🟢 Availability

**Availability** means systems and information should be accessible to
authorized users when they need them.

Security measures that support availability include:

- Backups
- Redundant systems
- Disaster recovery
- System maintenance

### Question to remember:

**Can authorized users access the system or information when needed?**

---

# 🧠 CIA Triad Example

Imagine a company has a database containing customer information.

### Confidentiality

Only authorized employees should be able to view sensitive customer
information.

### Integrity

Unauthorized users should not be able to secretly modify customer
records.

### Availability

Authorized employees should be able to access the database when they
need it to perform their jobs.

# 🛡️ Why These Fundamentals Matter in Cybersecurity

Understanding computer systems helps me understand what cybersecurity
professionals are actually protecting.

Computer components help explain:

- Where information is stored
- Where information is processed
- How programs execute
- How computers communicate
- What attackers may attempt to target

Understanding data helps explain what information needs protection.

The CIA Triad provides three important security objectives:

**Confidentiality → Protect information from unauthorized access**

**Integrity → Protect information from unauthorized modification**

**Availability → Keep information and systems accessible to authorized users**

These concepts will provide a foundation for learning more advanced
topics such as networking, operating systems, access control,
encryption, malware, vulnerability management, and incident response.
